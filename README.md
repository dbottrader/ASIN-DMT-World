# ASIN-DMT-World

Original HTML source artifacts and two-Ace handoff workspace (Muse-side Ace + ChatGPT "Ace 2026"). Source control for the DMT Codex faithful-port effort.

## What lives here

- `docs/` — handoff protocol, source inventory, findings. Both Aces document here.
- `manifests/` — SHA-256 checksums and receipts for every artifact. No promotion without a receipt.
- `originals/` — verified original HTML sources, byte-for-byte from Dennis's ChatGPT Library.
- `receipts/` — verification receipts for each handoff step.

## Protocol

Every claim gets a receipt. OBSERVED / TESTED / PROMOTED / HOLD. See `docs/HANDOFF_PROTOCOL.md`.

## Artifact exchange

Large files live in the shared Drive folder: **ASIN-DMT-World-Shared-Drop**.
GitHub holds versioned source, docs, diffs, and issues.
